\chapter{Contribution and Lessons Learned}
This internship produced a reusable engineering chain from historian-style data to an advisory prototype. On the data-science side, the work demonstrated why time ordering, a persistence baseline and leakage controls are essential for one-minute process data. It also showed that a change target can be more appropriate than absolute-level prediction when a current measurement is highly persistent.

On the software side, the project converted notebook logic into saved artifacts, a feature builder that reproduces the accepted feature contract, configuration-driven OPC mapping, tests for buffer, quality, storage and resilience behavior, containers, and a read-only dashboard. The work reinforced that industrial ML depends on traceability of feature meaning, model inputs, health state and output history.

The most important practical lesson is scope discipline. A simulator confirms software integration behavior but not production validity. Predictive importance does not prove causality. A model prediction does not authorize a process intervention. These distinctions make the delivered prototype more useful because they identify the exact information and validation needed before expanded deployment.
