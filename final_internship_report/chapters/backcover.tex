{\color{OcpBlue}\Huge\bfseries Machine Learning for TSP Free-Acid Monitoring\par}
\vspace{1cm}
{\Large Final-year engineering internship report\par}
\vspace{1.5cm}
\begin{minipage}{0.80\textwidth}
\centering
\textbf{Abstract.} This report documents a machine-learning project for estimating and forecasting \texttt{SLURRY\_FREE\_ACID} from one-minute TSP process data. It presents leakage-controlled feature engineering, target-anchored delta forecasting, target-free virtual sensing, stability-oriented model selection, and an advisory-only Docker and OPC UA replay prototype. The work is limited to one month of data and a laboratory replay environment. Further multi-month validation and read-only industrial shadow operation are required before operational adoption.
\end{minipage}
