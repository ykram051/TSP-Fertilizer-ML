\section{Software verification and reproducibility}
The repository provides a pinned \texttt{requirements.txt}, two Docker images (simulator and inference service) with an explicit \texttt{import lightgbm} smoke test at image build, a launcher script, a PyInstaller build of the dashboard and a ZIP packaging script. Six unit-test modules (buffer, configuration, quality shield, storage, service resilience, dashboard data access) cover 19 test functions. All saved artifacts used at runtime (feature registry, lag table, clipping bounds, model bundles) are versioned with the code, and every prediction records the model version and run identifier in the audit database.
